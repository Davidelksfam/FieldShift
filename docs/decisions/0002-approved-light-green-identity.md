# 0002 — Approved light-green Field Shift visual identity

- **Status:** Accepted visual direction (user explicitly liked the redesigned fresh dashboard and requested that it become team/agent branding guidance).
- **Date:** 2026-11-13.
- **Scope:** UI appearance, reusable color and typography tokens, icon/photography style, component and layout treatment.

## Context

The earlier Nabat Guide/Orbital Terraces concepts were replaced after the user supplied a clean farming-dashboard inspiration. The user approved the subsequent white-and-light-gray, fresh-green-accented Field Shift interactive redesign and requested binding brand guidance for collaborators and coding agents.

## Decision

Adopt [brand system](../brand/README.md), [identity](../brand/IDENTITY.md), [colors](../brand/COLORS.md), [design requirements](../brand/DESIGN.md) and [canonical CSS tokens](../brand/tokens.css). Root and web agent instructions should reference these canonical files instead of maintaining competing style guidance.

Accessibility corrections in the written system use the existing dark-green accent for small white-text CTAs; the originally previewed brighter green remains the prominent brand accent.

## Non-decisions and caveats

This does **not** approve any app framework, exact product feature list, crop recommendation, NASA dataset eligibility, calculation, auth method, dark mode, official NASA endorsement, or permission to build before event rules are verified. The approved HTML was a demonstrative visual concept with illustrative values, not validated analysis.

## Process

Future deviations/new colors must be proposed and reviewed in a scoped design PR. Screen reviews must cover Arabic RTL, English LTR, mobile, accessibility and source/uncertainty labels.
