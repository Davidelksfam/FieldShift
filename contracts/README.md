# Shared contracts

The user-authorized Scientific V2 work defines guarded JS/JSDoc contracts in [src/engine/v2/contracts.js](../src/engine/v2/contracts.js). [Contract semantics](../docs/engineering/SCIENTIFIC_V2_CONTRACTS.md) distinguish scientific quantity availability, feasibility and actionability. The [submitted implementation plan](../docs/engineering/FieldShift_Scientific_V2_Implementation_Plan.md) authorizes this versioned foundation.

Legacy payloads and prototype assumptions remain separate. Runtime source/units guards do not establish agronomic validity or independently verify a reference's contents.
