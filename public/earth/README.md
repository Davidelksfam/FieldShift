# Globe basemap

`earth.jpg` is the equirectangular Earth visualization texture distributed with Three.js examples, retrieved 2026-11-14 from https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg . The upstream project is https://github.com/mrdoob/three.js (MIT; license included here).

This is orientation imagery only. Its pixels do not supply the crop engine, establish current field conditions, or indicate scientific coverage. Quick-location markers represent the three configured benchmark coordinates; each retains its own source/fallback status. The map and geolocation choose points, not field polygons. No imagery timestamp is claimed for this texture.
